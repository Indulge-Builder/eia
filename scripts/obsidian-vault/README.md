# Obsidian vault tooling (archived)

This folder holds the hand written parts of the old Serene Obsidian vault that
used to live at `~/Desktop/serene-obsidian`. The vault itself was deleted on
2026-08-07. Everything in it was generated, so only these files were worth keeping.

## Why the vault went away

The vault was a rendered view of the graphify knowledge graph, not a source of
truth. Of its 4,179 notes:

- 4,124 were generated by `graphify export obsidian`
- 53 were copies of `docs/`, and 50 of those had already drifted out of date
- 2 were docs deleted from the repo in commit `d8100ac` (still in git history)
- 1 was empty

Nothing in it was unique except the files in this folder. It also sat outside the
repo and outside git, so no coding agent ever read it. Keeping it meant keeping a
fifth copy of the docs that nobody updated, which is worse than having no copy.

The retrieval stack that actually gets read is: the code, `CLAUDE.md`, `docs/`,
and `graphify-out/`.

## Important: this tooling no longer runs

`fix-vault.sh` post processes the output of `graphify export obsidian`. That
command **has been removed from graphify**. The current version only ships
`graphify export callflow-html`. Check with:

```bash
graphify --help | grep export
```

So these scripts are kept for reference and for the parts that are still reusable,
not as a working pipeline. If you ever want the vault back you would need to write
a new exporter first. `scripts/graph-to-obsidian.py` was an earlier attempt at
that, and it points at `~/Desktop/Serene Vault`, which no longer exists either.

## What each file is

| File | What it is | Still useful? |
| --- | --- | --- |
| `switch-graph.sh` | Flips the Obsidian graph view between community colours and Serene brand layer colours | Yes, in any vault, if you pair it with the two graph json files below |
| `obsidian-config/graph-serene.json` | Graph colouring by architecture layer, in the 5 Serene brand hues | Yes, it is the data `switch-graph.sh` needs |
| `obsidian-config/graph-colorful.json` | Graph colouring by community, 457 hues | Yes, same |
| `obsidian-config/snippets/serene-dark.css` | Obsidian theme matching the Serene app: dark canvas, champagne gold accent, serif headings | Yes, this is standalone and works in any vault |
| `Home.md` | The vault dashboard note, hand written prose | Reference only |
| `fix-vault.sh` | Post export beautifier: un-hides dotted notes, repairs wikilinks, sorts notes into layer folders | Reference only, its input command is gone |
| `graph.canvas` | 1.1 MB Obsidian canvas of the whole graph, grouped by community | Cannot be regenerated. Kept because it is the one thing that is truly gone otherwise. Drop it if you decide you do not want it. |
| `obsidian-config/app.json`, `appearance.json`, `core-plugins.json` | Vault settings | Reference only |

## If you want to browse the graph visually

You do not need Obsidian for this. Two things already do the job:

```bash
# interactive graph, written to graphify-out/graph.html
GRAPHIFY_VIZ_NODE_LIMIT=10000 graphify cluster-only .

# call flow / architecture HTML
graphify export callflow-html
```

## Keeping the graph fresh

This is the part that actually affects how well an agent finds things:

```bash
graphify update .                    # re-extract code, no API cost
graphify label . --backend claude    # re-name communities after a re-cluster
```
