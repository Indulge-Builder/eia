## 🎨 Switch the look

> [!tip] Two graph color schemes — fully reversible
> **Colorful** = one color per community (457 hues, the original).
> **Serene** = colored by architecture layer in the 5 brand hues.
> ```
> ./switch-graph.sh serene      # brand-colored by layer
> ./switch-graph.sh colorful    # original 457-community colors
> ./switch-graph.sh status      # which is live
> ```
> Run it in the vault folder, then **reopen the Graph view**. Notes are never touched.

> [!note]- Serene layer color key (when "serene" is active)
> | Color | Layer |

> [!info]- Serene visual theme (champagne-gold on dark)
> A CSS snippet ships **already enabled**: dark canvas, gold accent, serif headings — mirroring the Serene app. Toggle it any time at **Settings → Appearance → CSS snippets → `serene-dark`**. Turn it off there to return to plain Obsidian.

## 🔍 How to explore

> [!quote] Four good habits
> 1. **Browse the folders** (left explorer) — they mirror the codebase layers above.
> 2. **Hover** any `[[link]]` for an instant preview (page-preview is on).
> 3. Open a note, then check its **Backlinks** pane (right sidebar) to see what depends on it.
> 4. Use **Local Graph** (on any note) to see just that node's neighborhood — far calmer than the full 6,630-node graph.
